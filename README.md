# Uptime Pocket

Minimal endpoint uptime monitor.

I started this because the small tools I found for this job were either overloaded or required an account before I could do anything useful. The goal here is a fast, understandable browser app with sensible defaults.

## Current build

- Runs as a static web app
- Saves working data locally in the browser
- Search/filter box for the main workspace
- Add, edit, complete and remove items
- Export the current workspace as JSON
- Keyboard-friendly controls and responsive layout

## Try it

Open `index.html` directly or serve the folder with any static server. There is no build step.

## Direction

The first version intentionally stays small. The roadmap is in `ROADMAP.md`; the next milestone is better import/export and a project-specific data model instead of adding a pile of settings.

## Contributing

Bug reports with a reproducible example are especially useful. Small focused pull requests are easier to review than large rewrites.
